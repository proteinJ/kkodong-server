## 2. 핵심 기능 영역

### 2.1 소셜 산책 (Social Walking)
- 지도 기반 친구 실시간 위치 표시
- 그룹 산책 자동 감지: ① 명시적 수락, ② 100m 이내 + 일정 시간 이상 공동 이동 (GPS 오차 감안, 보수적 조건)
- 산책 파트너 매칭/모집
- 1:1 및 그룹 채팅

### 2.2 커뮤니티 (Community)
- 소셜 피드
- 산책 세션 기록
- 자동 생성 공유용 "완료 카드" (거리·시간·날씨·반려동물 사진 포함, 그룹이면 전원 포함, 9:16 인스타 스토리 비율) — 가장 강력한 바이럴 장치

### 2.3 시설 탐색 (Facility Discovery)
- 지도 위 동물병원, 펫스토어 등 반려동물 관련 레이어 (토글 방식)

### 2.4 반려동물 케어 (PET_CARE)
- 예방접종 스케줄 추적 (견종/나이 기반 자동 계산)
- 예방접종 D-day 푸시 알림 (`UNUserNotificationCenter`)
- 건강 일지 (체중 기록 + 그래프, Apple Charts)
- 다중 반려견 등록 (계정당 여러 마리)
- 견종별 훈련 가이드 (CMS 연동, Contentful 권장)
- 데이터 방식: 기본 스케줄은 앱 내장 + 관리자가 DB에서 오버라이드 가능한 하이브리드 구조

## 3. 수익 모델 (4개 축)

| 축 | 내용 |
|---|---|
| 구독 티어 | Free / Plus / Pro — 카드 커스터마이징, 반려견 3마리 이상 등록 등 **감성적으로 와닿는 행동**에 락온하여 전환 유도 |
| 산책 대행 수수료 | 커미션 기반 15~20% (Phase 3, 향후 기능) |
| 타겟 광고 | 지도 프리미엄 노출, 피드 네이티브 광고 — 견종/나이/산책 빈도 데이터 활용 |
| 인앱 커머스 | 완료 카드 굿즈, 산책 용품 판매 |

**전환 설계 원칙**: 기능적 제한보다 감성적으로 의미 있는 행동(카드 커스터마이징, 반려견 추가 등록)에 구독 락온을 배치 — 저항감이 낮고 실제 전환율이 높음.

## 4. 개발 로드맵

| Phase | 목표 | 주요 항목 |
|---|---|---|
| Phase 1 — MVP | 핵심 소셜 | 지도 & 친구 위치, 같이 산책 매칭, 1:1 채팅, 커뮤니티 피드 |
| Phase 2 — 성장 | 그룹 & 콘텐츠 | 그룹 산책 감지, 완료 카드, SNS 공유, 주변 시설 레이어 |
| Phase 3 — 수익화 | 대행 & 플랫폼 | 산책 대행 서비스, 인앱 결제, 워커 인증, 광고 & 제휴 |
